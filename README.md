# Titanicデータ分析

## 概要
KaggleのTitanicデータを用いて、生存率に影響する要因を分析

## 使用技術
- Python
- pandas
- seaborn

## 分析内容
・性別と生存率の関係  
・年齢と生存率の関係  
・同伴者（SibSp）と生存率の関係  

## 結果
・女性の方が生存率が高い  
・単独よりも同伴者ありの方が生存率が異なる傾向  
・家族構成が生存率に影響している可能性  

## 工夫した点
・仮説ベースで分析を実施  
・特徴量（FamilySizeなど）を作成
