# Titanic Survival Analysis

## 概要
本分析では、タイタニック号乗客データを用いて生存要因を分析した。
その結果、女性および小規模家族の乗客の生存率が特に高いことが確認された。

## ① 背景
Kaggleのタイタニック号乗客データを用いて、生存に影響する要因を分析する。

## ② 目的
どのような属性（性別・家族構成など）の乗客が生存しやすいかを明らかにする。

## ③ 結果
・女性の生存率は男性の約3.9倍  
・2〜4人の小規模家族（Small）の生存率は約80%と最も高い  

## ④ 結論
生存率には性別と家族構成が大きく影響しており、特に女性かつ小規模家族の乗客の生存率が最も高い傾向が確認された。

## ⑤ 示唆
救助の優先順位や家族単位での行動が、生存率に影響した可能性がある。
